# Narayanganj Smart City Weather

This is a weather and smart city dashboard for Narayanganj, Bangladesh.

The project provides current weather information, a 7-day forecast, an interactive map, and real-time traffic information in one simple dashboard.

## Features

- Current weather
- 7-day forecast
- Temperature, humidity and wind information
- UV index
- Interactive map
- Traffic information
- Modern dark interface

## Built With

Python, Streamlit, Open-Meteo, TomTom Traffic API and Folium.

## Run the Project

Install the required packages:

pip install -r requirements.txt

Then start the application:

streamlit run app.py

## Note

API keys are kept private using Streamlit secrets and are not included in this repository.
